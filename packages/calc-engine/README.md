# موتور محاسبات فرابهداشت

پکیج PHP خالص. نه Laravel می‌شناسد، نه پایگاه داده، نه ساعت. ورودی عددی
می‌گیرد و خروجی عددیِ نسخه‌دار می‌دهد.

چرا جدا از برنامه: اعداد ابزارهای بهداشت حرفه‌ای باید سال‌ها بعد هم همان
باشند. اگر منطق محاسبه لای کد وب باشد، یک ریفکتور بی‌ربط می‌تواند بی‌صدا
عددها را عوض کند و کسی نفهمد. این‌جا چنین چیزی ممکن نیست؛ دلیلش پایین‌تر.

## استفاده

```php
use Farabehdasht\CalcEngine\Engine;

$engine = Engine::withDefaultFormulas();

$calculation = $engine->run('wbgt-outdoor', [
    'natural_wet_bulb' => 25.0,
    'globe'            => 35.0,
    'dry_bulb'         => 30.0,
]);

$calculation->output('wbgt')->value;   // 27.5
$calculation->output('wbgt')->unit;    // Unit::Celsius
$calculation->formulaVersion;          // '1.0.0'
$calculation->notes;                   // یادداشت کیفی درباره همین داده
$calculation->disclaimers();           // سلب ادعا + محدودیت‌های رابطه
$calculation->toArray();               // شکل ذخیره‌سازی، کافی برای بازتولید
```

آرگومان سوم `run()` نسخه فرمول است. اگر ندهید آخرین نسخه اجرا می‌شود؛ برای
بازتولید یک محاسبه ذخیره‌شده **همیشه** نسخه ذخیره‌شده را بدهید:

```php
$engine->run($stored['formula']['id'], $inputs, $stored['formula']['version']);
```

## قواعد این پکیج

۱. **هر فرمول یک کلاس است و نسخه در نام کلاس می‌آید** — `WbgtIndoorV1`.
   تغییر رابطه یعنی `WbgtIndoorV2` کنار نسخه قبلی، نه ویرایش نسخه قبلی.
   نسخه قدیمی هیچ‌وقت حذف نمی‌شود چون محاسبه‌های ذخیره‌شده به آن ارجاع می‌دهند.
۲. **`compute()` خالص است** — نه ساعت، نه تصادف، نه فایل، نه شبکه. زمان و
   ذخیره‌سازی کار لایه بالاتر است.
۳. **هر فرمول منبعش را نام می‌برد** — `reference()` اجباری است و تست آن را
   بررسی می‌کند.
۴. **هر عدد واحد دارد** — `Quantity` بدون ذکر واحدِ انتظار مقدارش را نمی‌دهد.
   موتور واحد تبدیل نمی‌کند؛ تبدیل ضمنی همان‌جایی است که خطا خاموش می‌ماند.
۵. **هر خروجی سلب ادعا دارد** — `Calculation::DISCLAIMER` روی هر محاسبه‌ای
   می‌آید، به‌علاوه محدودیت‌های خود رابطه.

## قفل رفتار — چرا فرمول بی‌نسخه عوض نمی‌شود

سه لایه روی هم:

| لایه | کجاست | چه چیزی را می‌گیرد |
|---|---|---|
| رجیستری | `FormulaRegistry::register()` | ثبت دوباره یک `id@version` |
| تست طلایی | `tests/GoldenVectorTest.php` | خروجی‌ای که با موردهای مرجع نمی‌خواند |
| قفل اثر انگشت | `formulas.lock.json` | تغییر رفتار، حتی وقتی موردهای مرجع هم با آن «اصلاح» شده باشند |

لایه سوم مهم است. اگر کسی ضریب را عوض کند، تست طلایی قرمز می‌شود — ولی
وسوسه‌انگیزترین راه سبز کردنش این است که مقادیر مرجع را هم عوض کند. اثر
انگشت از روی همان موردهای مرجع و نتیجه اجرای واقعی‌شان ساخته می‌شود، پس آن
مسیر هم بسته است و تنها راه عبور، ساختن نسخه تازه است.

داخل اثر انگشت: شناسه، نسخه، قرارداد ورودی‌ها، واحد خروجی‌ها، نتیجه عددی هر
مورد مرجع تا ده رقم اعشار، و تعداد یادداشت‌های هر مورد.
بیرون از اثر انگشت: همه متن فارسی — برچسب، عنوان، منبع، محدودیت و متن
یادداشت. ویرایش نگارشی نباید نسخه بگیرد؛ تغییر عدد یا منطق یادداشت باید.

## افزودن فرمول تازه

۱. کلاس را در `src/Formulas/<Group>/<Name>V1.php` بسازید و `Formula` را پیاده کنید.
۲. به `DefaultFormulas::all()` اضافه کنید.
۳. فایل موردهای مرجع را در `golden/<id>@<version>.json` بنویسید. هر مورد باید
   `derivation` داشته باشد — حسابی که خواننده با ماشین‌حساب بازبینی می‌کند.
۴. یک بار اجرا کنید:

```bash
php packages/calc-engine/bin/lock-formulas.php
```

این اسکریپت فقط **اضافه** می‌کند. اگر رفتار نسخه‌ای که از قبل در قفل است
عوض شده باشد، به‌روز نمی‌کند و با خطا بیرون می‌آید.

## نسخه تازه یک فرمول موجود

کلاس `...V2` بسازید با همان `id()` و `version()` تازه. نسخه قبلی را دست
نزنید و فایل مرجعش را هم دست نزنید. هر دو در `DefaultFormulas::all()` می‌مانند.
`run()` بدون نسخه، تازه‌ترین را برمی‌دارد؛ محاسبه‌های ذخیره‌شده نسخه خودشان را
صدا می‌زنند.

## فرمول‌های موجود

| شناسه | نسخه | رابطه | منبع |
|---|---|---|---|
| `wbgt-indoor` | 1.0.0 | `WBGT = 0.7·Tnw + 0.3·Tg` | ISO 7243 |
| `wbgt-outdoor` | 1.0.0 | `WBGT = 0.7·Tnw + 0.2·Tg + 0.1·Ta` | ISO 7243 |
| `sound-pressure-sum` | 1.0.0 | `L = 10·log₁₀(Σ 10^(Lᵢ/10))` | IEC 61672-1 |

درباره مقادیر مرجع: این‌ها مثال حل‌شده کپی‌شده از یک نشریه نیستند. هر مورد،
اجرای دستی رابطه منتشرشده است و حسابش کنارش نوشته شده تا بازبینی‌پذیر باشد.
مورد چندباندی صدا از مسیر مستقلِ ترکیب دوبه‌دو و در اجرایی جدا از این پکیج
راستی‌آزمایی شده است.

## تست

از ریشه پروژه:

```bash
vendor/bin/phpunit --testsuite CalcEngine
```

`StandaloneTest` نگهبان استقلال پکیج است: متن `src/` را می‌خواند و اگر به
`Illuminate\`، `Laravel\`، `Filament\`، `App\` یا کمک‌تابع‌های Laravel ارجاعی
پیدا کند قرمز می‌شود، و `require` پکیج را هم بررسی می‌کند که چیزی جز `php`
نداشته باشد.
