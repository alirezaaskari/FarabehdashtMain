# برنامه کدنویسی فرابهداشت — بخش به بخش

هدف این سند: هر بخش از محصول یک **واحد مستقل و قابل ارتقا** باشد. وقتی شش ماه بعد خواستید
«بخش دوره‌ها» را عوض کنید، دقیقاً بدانید کدام پوشه را باز کنید و مطمئن باشید بقیه سیستم
نمی‌شکند.

## بخش ۰ — قراردادهای کد (پیش از نوشتن اولین خط)

### ساختار مخزن

```
farabehdasht/
├─ app/
│  ├─ Modules/            ← هر ماژول یک پوشه، با ساختار یکسان
│  ├─ Contracts/          ← رابط‌های بین‌ماژولی (تنها راه گفت‌وگوی ماژول‌ها)
│  ├─ Support/            ← ابزارهای مشترک: Money، JalaliDate، PersianNumber
│  └─ Providers/
├─ packages/
│  └─ calc-engine/        ← پکیج مستقل محاسبات، بدون وابستگی به Laravel
├─ config/
│  └─ modules.php         ← کلید روشن/خاموش هر ماژول
├─ resources/
│  ├─ views/              ← قالب‌های Blade
│  └─ css, js
├─ database/migrations/
├─ tests/
└─ docs/
```

### ساختار داخلی هر ماژول — همیشه یکسان

```
app/Modules/<Name>/
├─ README.md              ← این ماژول چه می‌کند · وابستگی‌ها · نقاط توسعه
├─ Domain/                ← Model، Enum، ValueObject
├─ Actions/               ← هر کلاس یک کار، یک متد اجرا
├─ Services/              ← منطقی که چند Action مشترک دارند
├─ Http/                  ← Controller، FormRequest، ViewModel
├─ Filament/              ← Resource و Page پنل مدیریت
├─ Policies/
├─ Events/ و Listeners/
├─ Contracts/             ← رابط‌هایی که این ماژول به بیرون می‌دهد
├─ Providers/<Name>ServiceProvider.php
├─ routes/web.php
├─ database/migrations/
├─ resources/views/
└─ tests/
```

### قواعد غیرقابل نقض — همین‌ها ارتقا را آسان می‌کنند

۱. **هیچ ماژولی Model ماژول دیگر را مستقیم import نمی‌کند.** فقط از طریق یک Interface در
   `app/Contracts` یا با گوش‌دادن به Event.
۲. **هر ماژول یک ServiceProvider دارد.** حذف ماژول = حذف پوشه + یک خط از `config/modules.php`.
۳. **هر ماژول README خودش را دارد** و بدون خواندن کد بقیه قابل فهم است.
۴. **منطق تجاری در Controller و Blade نوشته نمی‌شود** — فقط در Action و Service.
۵. **هر وضعیت یک Enum است**، نه رشته جادویی.
۶. **پول همیشه عدد صحیح تومان** با پسوند واحد در نام (`amount_toman`) و از طریق `Money` عبور می‌کند.
۷. **هر تغییر داده حساس یک Event منتشر می‌کند** تا Audit Log بدون دست‌بردن در کد ماژول کار کند.

### استاندارد کیفیت

`declare(strict_types=1)` در همه فایل‌ها · کلاس‌ها به‌صورت پیش‌فرض `final` ·
Laravel Pint (PSR-12) · PHPStan سطح ۶ به بالا · Pest برای تست ·
هر ماژول تست خودش را دارد · CI روی هر Pull Request: Pint + PHPStan + تست + بررسی دسترس‌پذیری.

**معیار پذیرش — نتیجه:** صفحه `/design-system` با کامپوننت‌های زنده بازتولید شد ·
