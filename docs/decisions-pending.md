# تصمیم‌های باز — نیازمند پاسخ مدیر

هیچ‌کدام از موارد زیر حدس زده نشده‌اند. تا پاسخ مدیر، پیاده‌سازی وابسته به آن‌ها شروع نمی‌شود.

**وضعیت:** ۱۲ مورد بسته شده است. هیچ‌کدام از موارد باز، بخش‌های
۵ تا ۱۶ را متوقف نمی‌کنند؛ فقط **بخش ۱۷ (استقرار)** به HOST-04، HOST-05 و
HOST-08 نیاز دارد — و هیچ‌کدام دیگر ریسک معماری نیستند، فقط جزئیات تنظیم.

## الف) مشخصات هاست

### آنچه از صفحه Server Information سی‌پنل تأیید شد

| مورد | مقدار | منبع |
|---|---|---|
| نوع هاست | **اشتراکی** | وجود `Shared IP Address` و بسته `WS-F` |
| سی‌پنل | ۱۳۶٫۰ (build 33) | همان صفحه |
| وب‌سرور | Apache 2.4.66 | همان صفحه |
| دیتابیس | **MariaDB 10.11.16** | همان صفحه |
| سیستم‌عامل | Linux x86_64 | همان صفحه |
| PHP | ۸٫۳ | تصمیم مدیر (A-01) |
| **دسترسی خط فرمان** | **ابزار Terminal سی‌پنل در دسترس است** | تأیید مدیر |

> **اثر MariaDB 10.11 روی کد:** نسخه LTS است و ستون `json`، ایندکس تا ۳۰۷۲ بایت
> و CTE را پشتیبانی می‌کند. هیچ‌کدام از مهاجرت‌های نوشته‌شده تا بخش ۴ نیاز به
> تغییر ندارند. مشکل قدیمی «۷۶۷ بایت» مربوط به MySQL 5.7 است و اینجا پیش نمی‌آید.

> **اثر Terminal روی استقرار (HOST-02):** روند استقرار **عادی** می‌ماند —
> `composer install --no-dev`، `php artisan migrate --force`،
> `php artisan config:cache` و `php artisan storage:link` همه روی خود سرور
> اجرا می‌شوند. راهکار اضطراری «ساخت vendor روی کامپیوتر و آپلود فشرده» و
> «مسیر محافظت‌شده مهاجرت در خود برنامه» **لازم نیست** و از نقشه راه حذف شد.
>
> یک نکته می‌ماند: `npm run build` روی هاست اشتراکی معمولاً به‌خاطر سقف RAM
> شکست می‌خورد. پس دارایی‌های ساخته‌شده (`public/build`) روی کامپیوتر ساخته و
> همان‌ها منتقل می‌شوند. این محدودیت به Terminal ربطی ندارد و همیشه برقرار است.

### هنوز باز

> **همه این‌ها را یک دستور جواب می‌دهد.** فایل `scripts/host-check.sh` را در
> ابزار Terminal سی‌پنل اجرا کنید (فقط می‌خواند، هیچ‌چیز را تغییر نمی‌دهد) و
> خروجی را بفرستید:
>
> ```bash
> bash ~/host-check.sh
> ```
>
> فقط HOST-04 و HOST-07 از اسکریپت درنمی‌آیند و باید از سی‌پنل یا پشتیبانی پرسیده شوند.

| کد | پرسش | اثر | کجا دیده می‌شود |
|---|---|---|---|
| HOST-04 | Document Root دامنه قابل تنظیم روی زیرپوشه `public` است؟ | امنیت؛ در غیر این صورت راهکار جایگزین لازم است | `Domains` → ستون Document Root |
| HOST-05 | کمترین بازه Cron Job؟ | صف، اعلان، تسویه زمان‌بندی‌شده | `Cron Jobs` → Common Settings |
| HOST-06 | سقف فضا و تعداد اینود؟ | حجم فایل‌های فروشگاه | نوار کناری → `Disk Usage` و `File Usage` |
| HOST-07 | سرور ایران است یا خارج؟ | سرعت، انتخاب درگاه، ملاحظات حقوقی | از پشتیبانی هاست بپرسید |
| HOST-08 | افزونه‌های `intl`، `bcmath`، `zip`، `fileinfo` روی PHP 8.3 فعال‌اند؟ | **بدون `intl` تاریخ شمسی کار نمی‌کند** | `Select PHP Version` → تب Extensions |
