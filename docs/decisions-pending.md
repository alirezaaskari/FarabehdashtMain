# تصمیم‌های باز — نیازمند پاسخ مدیر

هیچ‌کدام از موارد زیر حدس زده نشده‌اند. تا پاسخ مدیر، پیاده‌سازی وابسته به آن‌ها شروع نمی‌شود.

**وضعیت:** ۱۲ مورد بسته شده است. هیچ‌کدام از موارد باز، بخش‌های
۵ تا ۱۶ را متوقف نمی‌کنند؛ فقط **بخش ۱۷ (استقرار)** به HOST-04، HOST-05 و
HOST-08 نیاز دارد — و هیچ‌کدام دیگر ریسک معماری نیستند، فقط جزئیات تنظیم.

## الف) مشخصات هاست

### ⚠️ تصحیح مهم

خروجی اولیه `host-check` و صفحه Server Information اولی، مربوط به سرور **`z8`**
بود — یک هاست دیگر، نه هاست فرابهداشت. **همه آن اعداد باطل‌اند** و نباید مبنای
هیچ تصمیمی قرار بگیرند. سرور درست **`h9`** است.

### آنچه از صفحه Server Information سرور درست (`h9`) تأیید شد

| مورد | مقدار | منبع |
|---|---|---|
| نام سرور | **h9** | صفحه Server Information |
| بسته | WS-F | همان صفحه |
| نوع هاست | **اشتراکی روی CloudLinux** | `Shared IP Address` و هسته `…lve.el8` |
| سی‌پنل | ۱۳۶٫۰ (build 33) | همان صفحه |
| وب‌سرور | Apache 2.4.68 | همان صفحه |
| دیتابیس | **MariaDB 10.11.6** (نسخه `cll-lve`) | همان صفحه |
| هسته | `4.18.0-553.54.1.lve.el8` → CloudLinux 8 | همان صفحه |
| آی‌پی مشترک | `49.12.129.169` | همان صفحه |
| CPU سرور | ۳۲ هسته · بار ۵٫۹۹ · حافظه ۴۵٪ مصرف | Service Information |
| `sshd` | **در حال اجرا** | Service Information |
| `crond` | **در حال اجرا** | Service Information |
| PHP | ۸٫۳ | تصمیم مدیر (A-01) — نسخه دقیق روی این سرور هنوز تأیید نشده |

> **سرور خارج از ایران است (HOST-07).** آی‌پی `49.12.129.169` در بازه Hetzner
> (آلمان) است، و خود صفحه هم می‌گوید cPanel و Webmail «از طریق CDN ایران» در
> دسترس‌اند — یعنی مبدأ خارج است و CDN فقط درگاه ورود ایرانی است.
>
> سه پیامد: `composer install` احتمالاً بدون مشکل به GitHub می‌رسد (برعکس
> حالتی که سرور ایرانی باشد) · تأخیر کاربر ایرانی بیشتر است و CDN اهمیت پیدا
> می‌کند · بازگشت callback زرین‌پال از ایران به آلمان می‌آید و باید در تست
> پرداخت لحاظ شود.

> **CloudLinux یعنی سقف منابع per-account (LVE).** بر خلاف هاست معمولی، مقدار
> `memory_limit` در PHP سقف واقعی نیست؛ LVE سقف جداگانه‌ای برای حافظه، CPU و
> «Entry Processes» هر حساب می‌گذارد. این عددها باید از بخش
> **Resource Usage** سی‌پنل خوانده شوند، نه از `php -i`.

> **MariaDB 10.11.6:** همچنان نسخه LTS و برای همه مهاجرت‌های بخش ۱ تا ۴ کافی
> است. ستون `json`، ایندکس تا ۳۰۷۲ بایت و CTE را پشتیبانی می‌کند.

### هنوز باز — همه باید روی سرور `h9` دوباره بررسی شوند

| کد | پرسش | اثر |
|---|---|---|
| **HOST-02** | آیا ابزار **Terminal** روی همین حساب (`h9`) هست؟ | سرویس `sshd` روی سرور بالاست، ولی این یعنی سرور SSH دارد — نه لزوماً اینکه حساب شما اجازه دارد |
| **HOST-04** | Document Root دامنه قابل تنظیم روی زیرپوشه `public` است؟ | سی‌پنل → `Domains` → ستون Document Root |
| **HOST-05** | کمترین بازه Cron Job؟ | `crond` بالاست، پس زمان‌بندی ممکن است؛ بازه مجاز را سی‌پنل تعیین می‌کند |
| **HOST-06** | سقف فضا، اینود و **سقف LVE** (حافظه، CPU، Entry Processes)؟ | سی‌پنل → نوار کناری و بخش `Resource Usage`. روی CloudLinux این مهم‌ترین عدد است |
| **HOST-08** | نسخه دقیق PHP و افزونه‌های `intl`، `bcmath`، `zip`، `fileinfo`؟ | **بدون `intl` تاریخ شمسی کار نمی‌کند** |
| **HOST-09** | آیا `composer install` به packagist و GitHub می‌رسد؟ | چون سرور آلمان است، احتمال موفقیت زیاد است — ولی باید تست شود |

> هر شش مورد با اجرای بلوک `docs/host-quick-check.md` **روی Terminal سرور `h9`**
> جواب می‌گیرند، به‌جز HOST-04 و سقف‌های LVE که از رابط سی‌پنل خوانده می‌شوند.
