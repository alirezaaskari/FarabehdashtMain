# پذیرش نسخه ۱ — بخش دستی

هر چیزی که خودکارشدنی بود در CI است ([`README.md`](README.md)). اینها فقط روی
هاست واقعی یا گوشی واقعی معنا دارند و کارشان با مدیر است. هیچ‌کدام را کد یا
دستیار روی هاست زنده انجام نمی‌دهد (DEC-35).

برای هر بند، نتیجه و تاریخ را جلویش بنویسید؛ تصویر یا عدد را کنار همین فایل
بگذارید.

## ۱. پرداخت واقعی زرین‌پال (DEC-35)

پیش‌نیاز: `.env` هاست `FBH_PAYMENT_DRIVER=zarinpal`، `ZARINPAL_SANDBOX=false` و
`ZARINPAL_MERCHANT_ID` واقعی.

1. با یک حساب فروشنده، محصولی ۱۰٬۰۰۰ تومانی بسازید و از پنل مدیریت تأییدش کنید.
2. با یک حساب کاربر عادی (نه حساب مدیر در حالت «مشاهده به‌عنوان کاربر» — آن
   حالت حالا خرید را رد می‌کند) محصول را بخرید و با کارت واقعی بپردازید.
3. بررسی کنید:
   - صفحه موفقیت و لینک دانلود باز می‌شود؛
   - در پنل زرین‌پال تراکنش ۱۰۰٬۰۰۰ **ریال** دیده می‌شود (تبدیل فقط در آداپتور)؛
   - در پنل مدیریت، سفارش «پرداخت‌شده» است، کمیسیون ۲٬۰۰۰ و سهم فروشنده ۸٬۰۰۰ تومان.
4. از صفحه «بازگشت وجه» پنل، کل مبلغ را برگردانید. وجه به **کیف پول** خریدار
   برمی‌گردد، نه به کارت (`IssueRefund`)؛ اگر می‌خواهید پول به کارت برگردد، آن را
   جداگانه از پنل زرین‌پال انجام دهید.
5. روی هاست اجرا کنید و خروجی را نگه دارید:
   ```bash
   /usr/local/bin/ea-php84 artisan fbh:reconcile-wallets
   ```
   باید بدون اختلاف تمام شود.

## ۲. گوشی واقعی

روی Safari در iOS و Chrome در اندروید: صفحه اصلی، یک مقاله، یک ابزار (فرم را پر
کنید و نتیجه را ببینید)، ورود، میزکار.

- [ ] هنگام فوکوس روی فیلد، صفحه زوم نمی‌کند.
- [ ] منو و دکمه‌ها با انگشت راحت زده می‌شوند.
- [ ] عددها و واحدها (dB، ppm) وارونه نیستند.
- [ ] PDF گزارش روی گوشی باز می‌شود و فارسی‌اش درست است.

## ۳. کیبورد، مسیر کامل

فقط با Tab، Shift+Tab، Enter و Space: ورود ← یک ابزار ← محاسبه ← ذخیره ← افزودن
محصول به سبد ← صفحه پرداخت (پیش از درگاه متوقف شوید).

## ۴. «خطا فقط با رنگ نیست»

در فرم ورود و یک فرم ابزار، ورودی نادرست بدهید: کنار قاب قرمز، متن خطا هم باید
باشد. (تنها قاعده دسترس‌پذیری که ابزار خودکار نمی‌گیرد.)

## ۵. سرعت روی هاست

Lighthouse حالت موبایل (Chrome DevTools) روی صفحه اصلی، یک مقاله و یک ابزار:

| صفحه | LCP (≤ ۲٫۵ ثانیه) | CLS (≤ ۰٫۱) |
|---|---|---|
| `/` | | |
| یک مقاله | | |
| یک ابزار | | |

و زمان پاسخ از یک اینترنت ایرانی. اگر عددها بد بود، سقف LVE هاست (HOST-06) اول
بررسی می‌شود.

## ۶. Rich Results گوگل

در [Rich Results Test](https://search.google.com/test/rich-results) یک صفحه از هر
نوع: مقاله، اصطلاح واژه‌نامه، ماده، ابزار، دوره، محصول. فقط پس از خروج از staging
ممکن است، چون تا آن موقع `robots.txt` همه را می‌بندد؛ تا آن زمان گزینه «Code» و
چسباندن HTML صفحه کافی است.
