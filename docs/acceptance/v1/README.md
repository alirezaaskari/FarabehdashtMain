# گزارش پذیرش نسخه ۱ (بخش ۱۷-ب)

وضعیت در تاریخ ۲۰۲۶-۰۹-۲۴، روی شاخه‌ای که از `main` پس از مرج ۱۷-الف (PR #14) جدا شد.

**نتیجه: کد آماده انتشار است (DEC-36).** همه بررسی‌های خودکار سبزند و در CI
می‌مانند تا بعد از نسخه ۱ هم نگهبان باشند. آنچه مانده دستی است و فقط روی هاست
یا گوشی واقعی معنا دارد: [`manual-checklist.md`](manual-checklist.md). خروج از
staging تصمیم جدای مدیر است: بخش «چک‌لیست انتشار» در [`docs/deployment.md`](../../deployment.md).

دو ایراد واقعی که همین پذیرش پیدا کرد و در همین PR رفع شد:

1. **در حالت «مشاهده به‌عنوان کاربر» خرید باز بود.** `Impersonation::guardAgainstFinancialAction()`
   وجود داشت ولی هیچ جا صدا زده نمی‌شد؛ مدیر می‌توانست با حساب کاربر سبد را
   پرداخت کند، اشتراک بخرد یا در دوره ثبت‌نام کند. حالا قرارداد
   `App\Contracts\FinancialGuard` با میان‌افزار `financial` روی سه مسیر پرداخت و لغو تمدید اشتراک
   و خود Actionهای شروع پرداخت، پیش از ساختن هر سفارشی ۴۰۳ می‌دهد.
2. **فهرست مواد شیمیایی N+1 داشت:** برای هر ردیف حد مجاز و راه ورود جدا
   خوانده می‌شد (۵۰ ماده = ۱۰۰ پرس‌وجوی اضافه). `SubstanceFinder` حالا هر دو را
   از پیش بار می‌کند.

### یک انحراف از طرح: کف طول عنوان و توضیح

طرح «عنوان ۳۰–۶۰ و توضیح ۱۲۰–۱۶۰ نویسه» گفته بود. سقف‌ها در CI سخت‌اند (گوگل
بیشتر از آن را می‌بُرد)، ولی **کف** در CI نیست: توضیح کوتاه ایراد فنی نیست،
کار محتواست، و شکستن CI برای آن هر PR بی‌ربطی را قرمز می‌کرد. عنوانی که با نام
سایت از ۶۰ بگذرد، حالا نام سایت را کنار می‌گذارد به‌جای بریده‌شدن.

توضیح‌هایی که از ۱۲۰ نویسه کوتاه‌ترند (از `summary` محتوا یا تعریف ابزار می‌آیند):

| صفحه | طول توضیح |
|---|---|
| همه ۱۵ ابزار | ۴۸ تا ۸۴ |
| سه مقاله دانشنامه | ۶۸ تا ۷۲ |
| سه صفحه ماده | ۸۲ تا ۹۲ |
| فهرست مواد · فهرست دوره‌ها · فروشگاه | ۱۰۳ · ۵۱ · ۵۶ |
| صفحه شرایط استفاده | ۲۴ |

اینها با ویرایش خلاصه‌ها در پنل یا فایل‌های تعریف ابزار درست می‌شوند و کد
نمی‌خواهند.

## اجرای دوباره

```bash
composer run check                         # همه تست‌ها، از جمله tests/Feature/Acceptance

# بررسی مرورگری، روی سرور محلی با محتوای نمونه (همان کاری که CI می‌کند):
php artisan serve --port=8124 &
npm run a11y                               # صفحات عمومی + یک نمونه از هر فایل نقشه سایت
FBH_A11Y_MOBILE=09xxxxxxxxx FBH_SITEMAP=0 \
FBH_PAGES=/workspace,/workspace/wallet npm run a11y   # میزکار، با درایور پیامک log
```
